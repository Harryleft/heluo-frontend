# 图书详情界面优化计划

## 1. 目标
- 在不破坏现有检索与跳转链路的前提下，优化图书详情页的现代化布局与信息可读性。
- 保持“推荐资源”稳定展示：`名称 + 可点击跳转`。
- 控制改动范围，确保类型安全与可回归。

## 2. 范围
- 页面结构：`OverviewTab` 的主区与侧栏编排。
- 样式体系：`OverviewTab` 相关样式分层与响应式表现。
- 展示细节：封面卡、推荐资源卡、基础信息卡、内容介绍卡、地图卡。

## 3. 非目标
- 不改后端向量召回协议。
- 不改数据模型字段定义。
- 不引入新的三方 UI 框架。

## 6. 风险与防护
| 风险 | 触发条件 | 防护策略 |
|---|---|---|
| 样式改动影响其他实体详情页 | 复用 class 命名过广 | 仅改 `OverviewTab` 命名空间下样式 |
| 推荐资源卡回归 | 结构重排时误删 link | 回归测试校验链接选择器与 href |
| 响应式布局错位 | 侧栏 sticky 与移动端切换冲突 | 单独验证 1440/1024/768/375 断点 |
