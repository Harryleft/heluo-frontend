# 主导航“墨色导航带”最小实施方案

## 目标

按用户选中的第 3 张视觉稿，只重设计全局主导航：深蓝通栏承载“首页 / 人物专题 / 智能对话”，当前栏目使用金色文字与短金线。搜索、Logo、面包屑、页面内容、路由和交互保持不变。

## 当前问题

- 导航与搜索同处一行，层级松散；窄屏换行后尤其像临时拼接。
- 选中态依赖圆角胶囊、渐变和内阴影，与专题页的平面编辑风格冲突。
- 三个入口没有形成稳定的章节索引结构。

## 最小改动

1. 仅修改 `src/styles/_pages.css` 中全局页头与主导航规则，不改组件 DOM 和路由逻辑。
2. 页头内部允许两行布局：Logo 与搜索在上，主导航在下并横跨可用宽度。
3. 主导航使用 `var(--classic-primary)` 平面深蓝底；普通入口为低对比白色，当前入口为金色。
4. 当前入口用 `::after` 绘制短金线；移除胶囊圆角、边框、渐变和阴影。
5. 保留至少 44px 的触控高度，并在 711px 与 390px 视口检查横向溢出。

## 验证

- 先补 Vitest CSS 契约并确认旧样式失败。
- 修改样式后执行目标测试、全量 Vitest、生产构建和 ESLint。
- 使用选中的生成图作为视觉基准，在 `/topics/dufu-from-gongxian` 以 711 × 863 同状态截图对照。
- 检查导航链接可点击、当前态、横向溢出和浏览器控制台错误。
